# 📝 todoApp

A mobile-friendly note-taking application that allows users to quickly create, manage, and track tasks in real time. Designed with a focus on simplicity, responsiveness, and efficient state management.

---

## 🚀 Live Demo
- **Live App:** https://meera-develops.github.io/todoApp/  
- **Demo Video:** https://www.youtube.com/shorts/SGUAIv_gmF4

---

## 🛠 Tech Stack
- **Frontend:** React / React Native  
- **Development Environment:** Expo Go  
- **Design:** Figma  

---

## ✨ Features
- Add and manage notes/tasks dynamically  
- Mark tasks as complete with real-time UI updates  
- Track completed vs. pending items  
- Responsive, mobile-first interface  
- Multi-screen navigation for improved user experience  

---

## 🧠 Key Implementation Details
- Implemented state management using React hooks (`useState`) to handle dynamic task updates  
- Built reusable components for scalability and cleaner code structure  
- Designed user interface in Figma and translated designs into functional components  
- Utilized live reloading in Expo Go to accelerate development and testing
